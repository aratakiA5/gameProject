# 星界遠征録

4人の仲間を編成し、遺跡を踏破していくブラウザ向けミニRPGです。

## 遊び方

1. 仲間をクリックして最大4人まで編成します。
2. 「遠征開始」で現在の階層に挑戦します。
3. 勝利すると遺晶と遠征Ptを獲得し、次の階層が解放されます。
4. 仲間を一度クリックして育成対象にした後、「選択中を強化」で遺晶を消費して戦力を上げられます。
5. 支援・治癒役を編成すると戦闘時に補正が入ります。

## 起動

インストールは不要です。`index.html` をブラウザで開くだけでプレイできます。

## 現在の内容

- 6人の初期キャラクター
- 最大4人のパーティ編成
- 5階層の遺跡攻略
- キャラクター育成
- 編成ロールによる戦闘補正
- 遺晶・遠征Pt・デイリーミッション風の進行要素

今後はキャラクター固有スキル、装備、ガチャではなくゲーム内報酬での仲間加入、ボスギミック、セーブ機能などを拡張できます。
